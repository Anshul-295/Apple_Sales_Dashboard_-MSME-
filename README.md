# Apple Sales Dashboard

## MSME Internship Project

This project is developed as part of the MSME Internship Program under the domain of Junior Web Designing.

The Apple Sales Dashboard is a frontend-based web application designed using HTML, CSS, and JavaScript. The dashboard provides a modern Apple-inspired interface for product analytics, inventory tracking, and sales monitoring.

---

## Technologies Used

- HTML5
- CSS3
- JavaScript

---

## Features

- Responsive Dashboard UI
- Apple-inspired Design
- Monthly Sales Analytics
- Product Search Functionality
- Inventory Management Section
- Product Category Visualization
- Mobile Friendly Layout

---

## Project Objective

The main objective of this project is to create a professional frontend dashboard capable of displaying product analytics and inventory information in a modern user interface.
